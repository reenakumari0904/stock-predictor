# 📈 Stock Price Prediction Web App

A powerful Machine Learning based web application that helps users analyze and visualize stock market trends in real time.
Built with Python and Streamlit, the application provides interactive stock analysis, moving average visualization,
and data-driven insights for smarter decision-making.

---

## 🚀 Overview

This project uses historical stock market data to analyze price movements and visualize market trends dynamically.
Users can search for different stocks, explore moving averages, and gain meaningful insights through an interactive dashboard.

---

## 🌟 Key Features

📊 Real-Time Stock Data Analysis
📈 Interactive Stock Trend Visualization
📉 Moving Averages (MA50, MA100, MA200)
🔍 Dynamic Stock Search Functionality
⚡ Fast and Interactive Streamlit Interface
🧹 Data Preprocessing and Cleaning
📅 Time-Series Data Analysis
🌐 Deployment on Streamlit Cloud
